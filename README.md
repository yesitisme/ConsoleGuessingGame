# Endless Guessing Game 🎯

A sleek, color-coded console application built in C# and .NET. Features a clean single-screen interface, input validation, and real-time score tracking.

## ✨ Features
* **Clean Single-Screen UX:** Uses screen clearing and persistent headers to avoid console clutter.
* **Color-Coded Feedback:** Clear visual cues for scores, win states, and error validation.
* **Robust Input Handling:** Prevents crashes from non-numeric or invalid user inputs.
* **Game Loop:** Continuous gameplay until the user chooses to exit.

## 🚀 Getting Started

### Prerequisites
* [.NET 8.0 SDK](https://dotnet.microsoft.com/download) (or later)

### Running the Application
1. Clone the repository:
   ```bash
   git clone https://github.com/yesitisme/ConsoleGuessingGame.git
   cd ConsoleGuessingGame
   ```
2. Build and run the project:
   ```bash
   dotnet run
   ```
